# Монгол хэл — шалгалт засах систем

Монгол хэлний шалгалтын **бичиж хариулах асуултуудыг** багшийн жишиг
хариулттай харьцуулж, оноо автоматаар тооцох систем. Оюутны PDF шалгалтыг
уншиж, тестийн оноог PDF-ээс авч, бичгийн асуултуудыг дүгнээд нэг CSV файл
үүсгэнэ.

Систем нь хоёр хэсгээс бүрдэнэ:

- **Streamlit вэб апп** — багш асуулт, жишиг хариултаа бүртгэх, шалгалт
  шалгах, машины дүгнэлтийг турших.
- **CLI скрипт** — терминалнаас бүх PDF-ийг шалгаж CSV үүсгэх.

---

## Гол боломжууд

- Асуулт бүрд жишиг хариулт, дээд оноо, нэмэлт жишээ хариулт бүртгэнэ.
- Оюутны PDF-ээс тестийн оноо, бичгийн хариултыг автоматаар ялгаж уншина.
- Бичгийн хариултыг утгын ойролцоо байдлаар дүгнэнэ:
  - **Локал (TF-IDF)** — интернэтгүй, үнэгүй.
  - **Gemini (утгын)** — ижил утгатай өөр үгээр бичсэн хариултыг сайн танина.
  - **Хосолмол** — локал ба Gemini онооны дундаж.
- 2+ оноотой асуултад **хэсэгчилсэн оноо** өгнө.
- Үр дүнг `mongol-hel.csv` болгон татаж авна (Excel-д монгол үсэг зөв харагдана).
- **🧪 Дүгнэлт шалгах** хуудсаар асуулт бүрийн машины дүгнэлтийг туршиж,
  яагаад тухайн оноо гарсныг алхам алхмаар харна.

Дэлгэрэнгүй дүгнэх зааврыг [`GRADING.md`](GRADING.md)-аас үзнэ үү.

## Вэб аппын хуудсууд

### 📝 Үндсэн хуудас — Асуултын сан ба шалгалт шалгах

1. **1️⃣ Асуултын сан**
   - `Асуулт` — оюутны PDF доторх асуултын тексттэй ойролцоо байх тусам
     сайн танигдана.
   - `Жишиг хариулт` — багшийн зөв гэж үзсэн хариулт. Олон зөв хувилбар
     байвал `|` тэмдгээр тусгаарлана.
   - `Оноо` — тухайн асуултын дээд оноо.
   - **Хадгалах** эсвэл **Check** дарахад сан `reference_answers.json`
     файлд хадгалагдаж, өмнөх хувилбар `reference_answers.backup.json`
     болж нөөцлөгдөнө.
2. **2️⃣ Оюутны шалгалт шалгах**
   - Оюутны PDF файлуудыг upload хийнэ.
   - **Check — бүгдийг шалгах** дарна.
   - Дүнгийн хүснэгт, оюутан тус бүрийн дэлгэрэнгүй мэдээлэл гарч ирнэ.
   - **⬇️ CSV татах** товчоор `mongol-hel.csv` татна.

### 🧪 Дүгнэлт шалгах хуудас

Sidebar-аас **🧪 Дүгнэлт шалгах** хуудсыг нээнэ. Энэ хуудас нь багш
асуулт, хариултаа бүртгэсний дараа **машин хэрхэн дүгнэж байгааг**
шалгах зориулалттай.

- Бүртгэсэн асуултаас нэгийг сонгоно.
- Жишиг хариулт, сан дахь жишээ хариултуудыг харна.
- Туршилтын оюутны хариулт бичээд **🔍 Дүгнэх** дарна.
- Дараах мэдээлэл гарна:
  - нийт оноо ба дээд оноо;
  - ойролцоо байдлын хувь ба тохируулсан босго;
  - таарсан хэсгийн тоо (2+ оноотой асуултад);
  - машин яагаад ийм оноо өгсөн тухай тайлбар;
  - хэсэг тус бүрийн ойролцоо байдал, босго давсан эсэх.
- **🧾 Жишиг хариултаар шалгах** товчоор жишиг хариулт өөрөө бүтэн оноо
  авч байгаа эсэхийг шалгана.
- **3️⃣ Сангаа бүхэлд нь шалгах** хэсэгт:
  - бүх асуултын жишиг хариулт бүтэн оноо авч байгаа эсэх;
  - сан дахь жишээ хариултууд багшийн өмнө өгсөн оноотой таарч байгаа эсэх.

Эдгээр шалгалт нь жишиг хариулт хэт богино, босго хэт өндөр, эсвэл
асуултын тохиргоо буруу байгааг илрүүлэхэд тусална.

## Дүгнэх зарчим

Оюутны хариултыг багшийн жишиг хариулттай **утгын ойролцоо байдлаар**
харьцуулна.

| Арга | Тайлбар |
|---|---|
| **Локал (TF-IDF)** | Character n-gram TF-IDF cosine + fuzzy string matching. Интернэтгүй ажиллана. |
| **Gemini (утгын)** | Gemini хариултыг 0–100 оноогоор үнэлнэ. Ижил утгатай өөр үгээр бичсэн хариултыг сайн танина. |
| **Хосолмол (дундаж)** | Локал ба Gemini онооны дундаж. |

### Нэг оноотой асуулт

Ойролцоо байдал босгоос (анхны утга **65%**) дээш бол бүтэн оноо, доош бол
0 оноо.

### 2+ оноотой асуулт — хэсэгчилсэн оноо

Жишиг хариултыг хэсгүүдэд хувааж бичнэ. Дараах хэлбэрүүдийг дэмжинэ:

```text
1. Хөтөвч – бие засахад зориулсан сав.
2. Хатавч – гэрийн хаалганы хоёр хажуугийн хана.
3. Хонгиносон – нарийн, тод, цуурайтсан дуу авиа.
```

эсвэл:

```text
Хөтөвч – ... | Хатавч – ... | Хонгиносон – ...
```

Хэсэг бүрийг тусад нь харьцуулж, босго давсан хэсгийн хувьд оноо өгнө.
Жишээ нь 3 хэсэгтэй, 3 оноотой асуултад 1 хэсэг таарвал 1 оноо, 2 хэсэг
таарвал 2 оноо авна.

### Асуулт танигдахгүй бол

Оюутны PDF дээрх асуултын текст санд байгаа асуулттай хангалттай ойролцоо
биш бол (similarity < 0.30) тухайн асуултад 0 оноо өгч,
`⚠️ ... асуултын санд танигдсангүй` гэсэн анхааруулга гарна. Тухайн
асуултын текстийг санд байгаа тексттэй ойролцоо болгож засаад дахин
**Check** дарна.

## CSV формат

`mongol-hel.csv` файл нь:

```text
num,Оюутны код,Нийт оноо,30,29,28,...,1
1,NNS25C008,15,2,1,0,...
2,NNS25C042,14,1,1,1,...
```

- `num` — дарааллын дугаар.
- `Оюутны код` — PDF-ээс авсан оюутны код.
- `Нийт оноо` — тестийн + бичгийн оноо.
- `30 ... 1` — асуулт тус бүрийн оноо.

CSV нь UTF-8 BOM-той тул Excel дээр монгол үсэг зөв харагдана.

```text
etugen/
├── streamlit_app.py                  # Үндсэн Streamlit хуудас

├── app_shared.py                     # Хуудсуудын нийтлэг тохиргоо, сангийн функцууд

├── grade_exams.py                    # PDF уншигч + CLI
├── reference_answers.json            # Асуулт, жишиг хариултын сан
├── reference_answers.backup.json     # Автомат нөөц хуулбар
├── requirements.txt                  # Python сангууд
├── GRADING.md                        # Дүгнэх дэлгэрэнгүй заавар
├── muu-4-test/                       # Шалгах оюутны PDF-үүд
└── sain-4-training/                  # Багшийн дүгнэсэн сургалтын PDF-үүд
```

`reference_answers.json`-ийг Streamlit апп өөрөө удирддаг тул ихэвчлэн
гараар засах шаардлагагүй. Гэхдээ олон жишээ нэмэх бол файлыг шууд засах
нь илүү хялбар. Файлын бүтэц:

```json
{
  "questions": [
    {
      "id": "new-question-1",
      "type": "generic",
      "max_score": 2,
      "question": "Асуултын текст.",
      "reference_answer": "Багшийн жишиг хариулт.",
      "examples": [
        {"answer": "Бүтэн оноо авсан жишээ.", "score": 2},
        {"answer": "Хэсэгчилсэн жишээ.", "score": 1},
        {"answer": "Буруу жишээ.", "score": 0}
      ]
    }
  ]
}
```

## Алдаа гарвал

| Асуудал | Шийдэл |
|---|---|
| `pdftotext: command not found` | `sudo apt install poppler-utils` (эсвэл `brew install poppler`). |
| `ModuleNotFoundError` | `pip install -r requirements.txt` дахин ажиллуулна. |
| PDF-ийн асуулт санд танигдсангүй | Асуултын текстийг PDF дээрх тексттэй ойролцоо болгож засаад дахин Check дарна. |
| Gemini `HTTP 429` | Үнэгүй хязгаарт хүрсэн. Систем локал аргаар дүгнэнэ; түр хүлээгээд дахин оролдоно. |
| Монгол үсэг CSV-д буруу харагдав | CSV-г UTF-8 BOM-той үүсгэдэг; Excel дээр шууд нээхэд зөв байх ёстой. |
| Оноо хүлээснээс өөр гарвал | **🧪 Дүгнэлт шалгах** хуудсаар тухайн асуултыг шалгаж, босго болон жишиг хариултаа тохируулна. |
